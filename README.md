# Water Damage Restoration Belmont NC

Production-ready Astro static website for a local water damage restoration business in Belmont, NC.

**Domain:** waterdamagerestorationbelmontnc.us  
**Deploy target:** Cloudflare Pages  

## Requirements

- Node.js 18+ (20+ recommended)
- npm

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build (Cloudflare Pages)

**Build command:** `npm run build`  
**Output directory:** `dist`  
**Node version:** 20 (or 18+)

```bash
npm run build
```

The static site is written to `dist/`.

## Web3Forms setup

1. Create a free account at https://web3forms.com
2. Create an access key
3. Replace `YOUR_WEB3FORMS_ACCESS_KEY` in `src/pages/contact.astro` with your key
4. Optionally update the redirect URL if your domain differs

## Project structure

- `src/pages/` – all routes (home, services, areas, blog, legal, 404)
- `src/data/services.ts` – 20 service definitions
- `src/data/areas.ts` – service area / neighborhood pages
- `src/components/` – Header (with services dropdown), Footer, CTA
- `src/layouts/BaseLayout.astro` – SEO head, skip link, sticky mobile call button
- `public/robots.txt` – allows major search and AI crawlers
- `public/llms.txt` – structured summary for AI systems
- Sitemap generated by `@astrojs/sitemap` at build time

## Pages included

- Home
- Services overview + 20 individual service pages
- Service Areas overview + 8 area pages
- About, Contact (with honeypot + thank-you state)
- Blog index + 2 sample posts
- Privacy Policy, Terms of Use
- Custom 404

## Notes

- All copy is original; no fabricated licenses, ratings, or statistics
- Semantic HTML, skip link, focus styles, and WCAG-oriented patterns
- Sticky click-to-call on mobile viewports
- Canonical, Open Graph, and Twitter meta tags on every page
